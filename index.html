Panduan Instalasi

Cara pemasangan lengkap.

Langkah berikut berlaku untuk kedua extension. Pastikan file ZIP sudah diekstrak sebelum memuat foldernya ke browser.

chrome://extensions
01

Buka Halaman Extensions

Untuk Chrome: ketik chrome://extensions di address bar. Untuk Edge: ketik edge://extensions.

Settings
Developer mode
02

Aktifkan Developer Mode

Temukan dan nyalakan toggle Developer mode yang biasanya terletak di pojok kanan atas halaman.

Load unpacked
Pack extension
Pilih Folder (berisi manifest.json)
03

Load Unpacked

Klik tombol Load unpacked, lalu arahkan dan pilih folder hasil ekstrak yang di dalamnya terdapat file manifest.json.

Setup Lanjutan

Setelah instalasi berhasil

  1. Pastikan extension muncul di daftar browser dan toggle statusnya aktif.
  2. Login ke situs kerja sistem utama yang digunakan oleh tools.
  3. Refresh (F5) tab situs setelah extension dipastikan aktif.
  4. Buka UI extension dengan mengklik ikon extension / puzzle di pojok kanan atas browser.
  5. Untuk Scraper Tools: Masukkan License Key terlebih dahulu hingga indikator status menjadi AKTIF Minta License Key Ke Admin.
  6. Untuk SMS Tools: Cek status login akun, lalu jalankan workflow sesuai menu.
Troubleshooting

Jika muncul error

  • Jangan pilih file ZIP langsung. Anda wajib memilih folder hasil ekstrak.
  • Select Folder
  • Jika melakukan update/pembaruan, hapus versi lama terlebih dahulu, lalu Load unpacked folder versi baru, dan refresh tab web.

Penting: Jangan memindahkan atau menghapus folder extension dari komputer Anda setelah berhasil di-load. Jika folder berubah lokasi, browser akan mendeteksi error dan menonaktifkan extension tersebut sampai dipasang ulang dari lokasi yang baru.

Informasi

Pertanyaan umum (FAQ)

Apakah file ZIP langsung bisa dipilih saat instalasi?
Tidak bisa. Sistem browser mensyaratkan format folder. Ekstrak ZIP terlebih dahulu, kemudian saat menggunakan opsi "Load unpacked", pilih folder hasil ekstrak.
Apakah tools ini bisa dipasang di Microsoft Edge?
Sangat bisa. Extension ini berbasis mesin Chromium, sehingga kompatibel dengan Microsoft Edge. Anda hanya perlu membuka halaman Extensions di Edge, mengaktifkan Developer mode, dan menekan Load unpacked sama halnya seperti di Google Chrome.
Kenapa menu scraper di extension masih terkunci/abu-abu?
Pada Scraper Tools V3 Dan SMS TOOLS V3, perlindungan keamanan diterapkan. Menu utama dirancang agar baru bisa diakses (terbuka) setelah License Key yang sah dimasukkan dan diverifikasi secara online hingga status berubah menjadi "AKTIF".
Apakah perlu login ulang ke sistem kerja setelah instalasi?
Silakan ikuti status login yang ditampilkan pada antarmuka extension. Jika session web belum terbaca oleh extension, lakukan login ulang secara normal di tab situs kerja Anda, lalu refresh halaman tersebut, dan buka panel extension kembali.
