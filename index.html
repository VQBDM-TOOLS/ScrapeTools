SETUP

Setelah extension berhasil dipasang

  1. Pastikan extension muncul di daftar dan statusnya aktif.
  2. Login ke situs kerja yang digunakan oleh tools.
  3. Refresh tab situs setelah extension aktif.
  4. Buka extension dari ikon Extensions / puzzle.
  5. Untuk Scraper Tools, masukkan license key terlebih dahulu sampai status menjadi AKTIF.
  6. Untuk SMS Tools, cek status login lalu jalankan workflow sesuai menu yang tersedia.

Jika muncul error

  • Jangan pilih file ZIP langsung. Pilih folder hasil ekstrak.
  • Pastikan file manifest.json berada langsung di dalam folder yang dipilih.
  • Jika extension diperbarui, hapus versi lama lalu Load unpacked versi terbaru.
  • Refresh halaman situs setelah extension diaktifkan.
Tip: jangan memindahkan atau menghapus folder extension setelah di-load. Jika folder berubah lokasi, browser dapat menonaktifkan extension sampai dipasang ulang.
FAQ

Pertanyaan umum.

Apakah ZIP langsung bisa dipilih?

Tidak. Ekstrak ZIP terlebih dahulu, kemudian pilih folder yang di dalamnya terdapat file manifest.json.

Bisa dipasang di Microsoft Edge?

Extension berbasis Chromium dapat dimuat melalui halaman Edge Extensions menggunakan Developer mode dan Load unpacked.

Kenapa menu scraper masih terkunci?

Pada Scraper Tools, menu SCRAPE dirancang terbuka setelah license berhasil diaktifkan.

Perlu login ulang setelah instalasi?

Ikuti status login pada extension. Jika session belum terbaca, login di tab situs lalu refresh halaman dan buka extension kembali.
