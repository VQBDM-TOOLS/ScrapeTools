Cara Instalasi di Chrome

  1. Download ZIP di atas.
  2. Extract ZIP ke folder di komputer.
  3. Buka chrome://extensions.
  4. Aktifkan Developer mode.
  5. Klik Load unpacked.
  6. Pilih folder hasil extract extension.
  7. Extension Scraper Tools V1 siap digunakan.

Aktivasi License

  1. Buka Scraper Tools V1.
  2. Scroll ke menu Lisensi di bagian paling bawah.
  3. Masukkan License Key dari admin.
  4. Klik Aktivasi.
Ketentuan: 1 License = 1 PC dan berlaku 30 hari sejak aktivasi pertama. License disimpan dan diverifikasi secara offline oleh extension.

Jika License Bermasalah

Jika license sudah terikat pada PC lain atau sudah expired, hubungi admin untuk mendapatkan key baru.
