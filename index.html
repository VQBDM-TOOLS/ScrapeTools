Cara Penggunaan

Ikuti langkah sesuai tools yang ingin digunakan.

01

Download & Extract

Download ZIP tools pilihan, kemudian extract ke folder yang mudah ditemukan. Jangan hapus folder setelah extension dipasang.

02

Install di Chrome

Buka chrome://extensions, aktifkan Developer mode, pilih Load unpacked, lalu pilih folder hasil extract.

03

Jalankan Tools

Buka tab SOSI/CCO Agent sesuai kebutuhan, pastikan sudah login, lalu buka extension dan jalankan fitur yang tersedia.

Panduan Per Tools

Scraper Tools V1

1. Extract ZIP → buka chrome://extensions → Developer mode → Load unpacked.
2. Pilih folder hasil extract.
3. Buka extension Scraper Tools V1.
4. Masukkan License Key dari Owner pada menu LICENSE.
5. Klik AKTIVASI. Setelah valid, menu SCRAPE dapat digunakan.
6. Jika license expired/revoked/device mismatch, menu SCRAPE akan terkunci kembali.

SMS Tools V1

1. Extract ZIP → hapus versi BantuSaku sebelumnya jika ada.
2. Buka chrome://extensions → Developer mode → Load unpacked.
3. Login ke cco-agent.bantusaku.id dan refresh halaman SOSI.
4. Pastikan tab SOSI aktif, kemudian buka extension.
5. Pastikan status Login Aktif, lalu jalankan Scrape.
6. Jika scraper tidak berjalan, cek menu LOG pada extension.
