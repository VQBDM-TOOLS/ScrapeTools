Tutorial Pemasangan

Ikuti 5 langkah sederhana berikut setelah ZIP selesai di-download.

01

Download

Klik tombol download tool yang diperlukan.

02

Extract ZIP

Klik kanan file ZIP → Extract All sampai menjadi folder.

03

Buka Chrome

Ketik chrome://extensions pada address bar.

04

Developer Mode

Aktifkan Developer mode di pojok kanan atas.

05

Load unpacked

Klik Load unpacked, pilih folder extension, lalu selesai.

⚠ Catatan: Jangan memilih file ZIP langsung pada Load unpacked. Pastikan ZIP sudah di-extract dan pilih folder yang berisi file manifest.json.

Jika Extension Tidak Muncul

Checklist cepat sebelum menghubungi support.

Folder yang dipilih salah?Pastikan folder yang dipilih langsung berisi manifest.json, bukan folder induk yang masih berisi folder lain.
Developer mode belum aktif?Buka chrome://extensions lalu aktifkan tombol Developer mode.
Chrome memblokir extension?Gunakan instalasi melalui Load unpacked untuk source extension yang diberikan.
Butuh update versi?Hapus versi lama, download paket terbaru, extract kembali, kemudian Load unpacked.
