CARA MENGGUNAKAN

3 langkah sederhana

Client cukup download paket, ekstrak, lalu pasang extension di Chrome.

01 / DOWNLOAD

Pilih tool

Klik tombol download pada tool yang dibutuhkan. File akan tersimpan dalam bentuk ZIP.

02 / EXTRACT

Ekstrak ZIP

Extract file ZIP ke folder khusus di komputer. Jangan menghapus file di dalam folder extension.

03 / CHROME

Load extension

Buka Chrome Extensions → Developer mode → Load unpacked, lalu pilih folder extension.

Untuk keamanan, client sebaiknya menggunakan file yang dibagikan dari paket resmi ini.
